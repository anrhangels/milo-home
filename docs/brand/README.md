# Визуальный стиль Milo Home

[Главная](../../README.md) · [English](../../README.en.md)

Маскот — дружелюбный призрак с короной, предоставленный владельцем проекта. Новая адаптация сохраняет силуэт и подмигивание, добавляя спокойную тёмную основу и тёплый акцент.

## Файлы

- `milo-icon.png` — знак512×512 для документации.
- `hero-ru.webp` / `hero-en.webp` — обложки1800×1040 с настоящим снимком Haier.
- `updates-ru.webp` / `updates-en.webp` — галерея1800×1000 с исходными снимками эмулятора.
- `social-preview.png` — обложка1280×640 для ссылок на репозиторий.
- Android: иконки48/72/96/144/192px в mipmap-ресурсах; TV banner320×180.

Маскот создан встроенным инструментом генерации изображений OpenAI по двум изображениям владельца. Обложки — программная вёрстка вокруг исходных фотографий и скриншотов; содержимое экранов не генерировалось и не перерисовывалось. При экспорте фотографии удалены метаданные файла.

Для повторного экспорта макетов установите зависимости из `tools/branding/package.json` и выполните `node tools/branding/render.cjs`. Это инструмент оформления документации; Sharp не входит в APK. Исходные PNG-снимки сохранены отдельно, чтобы их можно было проверить без декоративной рамки.

Релизы test-v1.0.0 и test-v1.1.0-rc.1 были выпущены до обновления брендинга. Новый знак относится к текущим исходникам и следующим сборкам; опубликованные ранее APK не заменялись.
