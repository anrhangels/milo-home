# Как устроен Milo Home

Milo Home — нативное Java-приложение для Android TV с Android8/API26 и выше. Исходный идентификатор com.gathin.tvhome сохранён для совместимости; это не позволяет обойти проверку подписи Android.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| MainActivity, AppAdapter, Config | Домашний экран, карточки, фокус пульта, встроенные настройки и совместимые конфигурации |
| LauncherSettingsActivity, SettingsPreview | Разделы настроек, сохранение выбора и статичный предпросмотр оформления |
| UpdatePolicy, UpdateSchedule, UpdateJobService | Добровольные фоновые проверки через Android JobScheduler; 6/24ч, без постоянного процесса |
| BugReportActivity, BugReportSnapshot, BugReportQr | Разовый локальный снимок разрешённых характеристик и QR для заполненного пользователем обращения GitHub; без серверной отправки |
| UpdateManager, UpdateHttp | Асинхронная проверка Releases, кэш, ограниченные запросы и загрузка |
| UpdateFeed, UpdateRelease | Отбор канала, подписи, версии и варианта |
| UpdateApk | SHA-256, криптографическая подпись и проверка реального содержимого APK |
| UpdateUi, UpdateButton | Выбор Stable/RC, согласие, прогресс и штатный установщик |
| DpiClient / DpiState | Только вариант byedpi: защищённый IPC с отдельным backend |

Standard компилируется с BYEDPI_ENABLED=false; R8 удаляет недостижимый код управления. Manifest-overlay исключает TV_CONTROL и видимость backend-пакета. Wi-Fi открывает системные настройки. Byedpi добавляет управление парным backend; сам VPN не встраивается в процесс лаунчера.

Оба варианта — альтернативные сборки одного package. Встроенный обновлятор никогда не переключает их автоматически: variant сверяется сначала в release-метаданных, затем в manifest APK. Stable и RC внутри одного варианта используют один постоянный ключ.

## Жизненный цикл

Постоянной службы обновлений, сервера и телеметрии нет. По умолчанию проверка выполняется при открытии Milo, с кэшем на 24ч. Пользователь может отключить автопроверки полностью либо выбрать фоновые задания на 6/24ч. В ручном режиме сетевой запрос возможен только по явной команде. Задания требуют сети, могут быть отложены Android и не скачивают APK. После перезагрузки задание регистрируется при следующем запуске Milo; постоянной службы и boot receiver нет. Уход с Home отменяет незавершённую передачу. До Android-установщика файл проходит проверки; разрешение источника и установка остаются системными экранами.

Настройки темы, конфигурация карточек, встроенная библиотека и поддерживаемые расширения сохранены из исходной реализации. Пресеты, старые addons и наборы отключения пакетов не нужны для сборки и удалены из текущего репозитория. Источник и лицензии: [CREDITS](../CREDITS.md).
