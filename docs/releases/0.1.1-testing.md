# Milo Home 0.1.1 — upstream review and testing

Reviewed on 28 October2026. Upstream latest release: [CleanYourTV 3.1.0](https://github.com/Gathin23/cleanyourtv/releases/tag/v3.1.0), published 27 October2026, commit 874ffd7b35cb18540e295d5b8fa500168d403e95. Milo versionCode116 follows Stable 115. The upstream TV/model counts and non-Android tracking guide are not Milo launcher compatibility claims.

## Selective integration

| Upstream change | Milo adaptation |
| --- | --- |
| Remote press dispatch, #1287 | Shared per-device/key/scancode state, deduplication across helpers, timed hold and repeat handling. Callback uses application context and checks interactive display state. No background polling. |
| Activity targets | Explicit package/activity supported after input: targets are checked, with permission failures caught. |
| Vendor keycodes, #1785 | Configured normal app keys>=1000 are handled by focused Home, without remapping ordinary navigation/volume keys. |
| Double-Home glow, #1988 | Restore unfinished shelf/glow fades on the same card; existing disabled/reduced-animation path remains intact. |
| Compact icons, #1756 | Scale icon/margins inside smaller tiles, retaining normal-size cards. |
| Wallpaper timer, #1900 | At most2seconds of tolerance avoids skipping an entire minute rotation. |
| Android 9 Inputs, #1716 | Post opening beyond the extra lifecycle pause, retaining Milo's settings-anchor fallback. |
| Missing settings handler | AOSP TV settings explicit fallback; its package is explicitly visible under Android 11 package visibility. |
| Translations | Swedish base strings, selected existing translation updates, all29 available base locales registered for Android 13+. Milo-specific untranslated strings fall back to English. |

The release does not import forced Home at power-on, automatic cleanup/disable lists, restart actions, a second VPN pill, connected-input folding or the addon catalog. Full upstream locale/config, front:/guide: mappings and icon_tiles options are not claimed. Milo's own updater,edition checks,signature checks,shared artwork caches,quick panel and ByeByeDPI integration are retained. The plugin/style concept remains a separate future change.

## Validation

- Both editions:272 JVM tests, Android Lint and optimized non-debuggable builds;17 Python tooling tests and public-tree privacy scan.
- Added pure press tests cover chorded keys,two devices,duplicate helper delivery,cancellation,missing DOWN,autorepeat and input/activity separation; wallpaper test covers early timer jitter.
-11 tests on isolated Android 11 emulator: two new runtime regressions (interrupted shelf/glow recovery and a long press opening an own-app report screen before release, without also running tap), plus existing panel return,external volume events,clock preferences,hidden/screen-off lifecycle and artwork/library checks.
- The report screen is a local test target; no issue was submitted and no streaming app was launched.
- Optimized APK UI passed all six settings sections,library first-letter filtering and quick settings; the installed UI-tested APK matched the final local minified build. The emulator was stopped after testing. Actual public release verification passed (see below). The physical TV is unchanged in this task. No CPU/RAM percentage improvement is claimed; Android 9/vendor-specific hardware behaviors are not physically validated here.

## Reproduce

Run the BUILDING.md commands for both variants and the Python release tests. For native tests build byedpi with -PmiloInstrumented -PmiloUpdateTrack=test,install the app and test APK on an isolated Android 11 emulator,then run Upstream31Test,MenuReturnTest,QuickVolumeTest,ClockAppearanceTest,OptimizationLifecycleTest and OptimizationLibraryTest. Use an explicit emulator serial. Production release APKs must remain non-debuggable and use the existing permanent signing key.

After publication,download both assets and verify their real manifests,edition, versionCode 116,versionName 0.1.1,signing certificate,SHA-256 and embedded-backend policy against release metadata. The physical TV can update through its normal user-confirmed updater; there is no silent installation.
