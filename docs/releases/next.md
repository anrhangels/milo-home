Milo Home now has two editions: Standard (Wi-Fi settings, no ByeByeDPI control permission) and ByeByeDPI (paired protected backend integration).
Both have the new crowned mascot app icon and independent Stable/RC update selection. Edition is checked in release metadata and the actual APK.
Keep your factory HOME available. Existing installations require compatible signing identity; the original Haier key is unavailable, so do not uninstall it to force this update.
