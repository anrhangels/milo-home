# Milo Home 0.1.2

Выбранные исправления CleanYourTV 3.2 с сохранением привычного интерфейса Milo.

- Удержание кнопки отменяется, если обслуживающий её обработчик отключён. Если второй обработчик продолжает работать, действие передаётся ему без повторного запуска.
- Удержание также отменяется при передаче управления подключённому геймпаду.
- Исправлено направление текста и заголовка библиотеки для языков справа налево.
- Добавлен основной перевод на испанский для Латинской Америки. Новые настройки Milo без перевода используют английский.

Milo-Home.apk — обычная версия. Milo-Home-ByeByeDPI.apk — версия с установщиком ByeByeDPI. Устанавливайте свой вариант поверх предыдущего.

---

Selected CleanYourTV 3.2 fixes, keeping Milo’s familiar interface.

- Cancel pending held-key actions when their helper disconnects, or transfer them to the remaining helper without duplicate launches.
- Cancel pending holds when key filtering is handed over to a gamepad.
- Correct right-to-left library text and header alignment.
- Add the Latin American Spanish base translation. Untranslated Milo settings fall back to English.

Milo-Home.apk is the standard edition. Milo-Home-ByeByeDPI.apk includes the ByeByeDPI installer. Update using the same edition.
