A simpler home for your Android TV.

### Download
- **MiloHome-standard.apk** — recommended for most people.
- **MiloHome-byedpi.apk** — optional integration with the paired ByeByeDPI backend.

Choose one launcher APK, not both. The network edition needs the matching backend described in the installation guide.

### About this version
This starts Milo's public numbering at **0.0.3**, bringing the current launcher into one clear release. It is not a downgrade: the internal Android version code is **104**, above previous builds. Both APKs retain the permanent Milo signing certificate and the new mascot icon.

[Installation](https://github.com/anrhangels/milo-home/blob/milo-main/docs/START.md) · [Русский](https://github.com/anrhangels/milo-home/blob/milo-main/docs/START.ru.md)

Keep your original home app available. A signing conflict needs the documented migration procedure; do not uninstall just to force an update. Early separate-edition updater clients may require this one manual download, especially ByeByeDPI; this release supports both editions in one release feed. Future updates keep your selected edition.
