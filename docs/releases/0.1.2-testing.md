# Milo Home 0.1.2 — upstream integration

Source: CleanYourTV v3.2.0 (`42fe7b09d61fb9175cb03b8c659cd63c9c1dd9a4`), published 29 October 2026.

Included: helper ownership/cancellation/handover of pending remote holds (six upstream regression cases), cancellation when gamepad passthrough drops the key filter, RTL library alignment, Latin American Spanish base strings filtered to resources implemented by Milo.

Already covered in Milo: the idle clock is gated by resumed + interactive state. The upstream date-width fix targets its relocated date column; Milo retains its original date layout and does not implement that relocation.

Deferred: seasonal Halloween rendering/assets, new add-ons and catalog, boot-network waiting, additional VPN pill, remote action words/URI actions, unrelated cleanup/device scripts. No extra background worker, permission, automatic package change or default visual effect was added. No compatibility-count claims are inherited from upstream.

Validation: 278 JVM tests per edition (zero failures/errors), Android Lint and optimized release APK builds for Standard and ByeByeDPI; 17 Python release tests; public-tree privacy scan and diff check passed. Six new regression cases cover helper cancellation, handover, tap preservation and later presses. Local artifacts use the isolated test update track and local debug signature; official publishing builds use the permanent production signature. No emulator or physical-TV UI tests were run for this patch. Physical TV not modified.
