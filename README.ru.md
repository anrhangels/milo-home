# Milo Home

Независимая модификация [CleanYourTV](https://github.com/Gathin23/cleanyourtv), разработанного **Gathin23**.
Автор и владелец модификации — [anrhangels](https://github.com/anrhangels), помощь в разработке — **OpenAI Codex**.
Это не официальный релиз CleanYourTV. [English README](README.md).

Сохранены исходные обои, темы, лёгкий нативный Java-интерфейс и навигация пультом.
Кнопка Wi-Fi открывает меню ByeByeDPI / «Настройки Wi-Fi». Новая зелёная кнопка справа от «Настройки»
показывается только при совместимом обновлении. В меню доступны «Релиз» и «RC-версия»;
скачивание начинается после «Да», индикатор отражает полученные байты.
Перед штатным установщиком проверяются SHA-256, настоящая APK-подпись, package, versionCode, Android API и ABI.
Токена GitHub в приложении нет. Постоянной службы обновлений нет, повторная успешная проверка — через 24 часа.

Основное тестовое устройство прежней модификации — Haier 32 Smart TV BX / Android 11 / ARM32 / около 907 МиБ RAM.
Обновлятор отдельно испытывается в Android 11 эмуляторе: это не подтверждение его работы на Haier.
Реальные демонстрационные снимки из эмулятора опубликованы в [Screenshots](README.md#screenshots).
В кадрах используется помеченный локальный тестовый манифест, а не вымышленный опубликованный релиз.

Перед установкой прочитайте [UPDATING](docs/UPDATING.md) и [SIGNING](docs/SIGNING.md).
Идентификатор остаётся `com.gathin.tvhome`. Новый постоянный ключ напрямую не заменяет старую подпись;
нельзя удалять лаунчер и данные ради обхода несовместимости. Интеграция ByeByeDPI требует защищённой
парной сборки backend с согласованной подписью, а не произвольного официального APK.

Обновлятор не переназначает HOME, не включает отключённые системные пакеты, не меняет сеть и не запускает debloat.
Автозагрузка APK и автоматическая установка RC отсутствуют. Все релизы подписываются одним постоянным ключом.
Сборка и релизы: [BUILDING](docs/BUILDING.md), [RELEASE_CHANNELS](docs/RELEASE_CHANNELS.md).
Возврат к рабочей версии: [ROLLBACK](docs/ROLLBACK.md), с новым большим versionCode вместо удаления приложения.
